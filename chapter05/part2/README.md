# 실습과제 1

### 참조에 의한 호출(Call by Reference)과 주소에 의한 호출(Call by Address)의 차이점

C++에서 두 방식 모두 함수 내부에서 원본 데이터를 직접 수정할 수 있게 해 주지만, 전달된 인자(Argument)를 매개변수(Parameter)로 다루는 문법적 메커니즘에 명확한 차이가 있습니다.

1. **주소에 의한 호출 (Call by Address / Call by Pointer)**
   * **개념:** 함수 호출 시 인자의 '메모리 주소'를 함수의 매개변수인 '포인터(Pointer) 변수'로 전달하는 방식입니다.
   * **문법 및 동작:** 함수 선언 시 포인터 기호(`*`)를 사용하며, 호출할 때는 주소 연산자(`&`)를 통해 변수의 물리적 주소를 넘깁니다. 함수 내부에서 원본 값에 접근하거나 값을 수정하려면 반드시 역참조 연산자(`*`)를 사용하여 메모리 주소를 따라가야 합니다.
   * **특성:** 포인터 변수 자체가 별도의 메모리 공간을 차지하며, 널 포인터(NULL 또는 nullptr) 값을 가질 수 있고, 실행 도중 다른 주소를 가리키도록 재할당이 가능합니다.

2. **참조에 의한 호출 (Call by Reference)**
   * **개념:** 함수의 매개변수로 '참조자(Reference)'를 선언하여, 전달된 원본 변수에 대한 '별칭(Alias)'을 생성하는 방식입니다.
   * **문법 및 동작:** 함수 선언 시 참조 기호(`&`)를 사용합니다. 호출 시에는 값에 의한 호출(Call by Value)처럼 변수 이름만 그대로 전달하며, 함수 내부에서도 별도의 역참조 연산 없이 일반 변수처럼 접근하고 수정할 수 있습니다.
   * **특성:** 참조자는 내부적으로 포인터로 구현되지만 문법상 별도의 메모리를 차지하는 것처럼 다뤄지지 않습니다. 널(Null) 값을 가질 수 없으며, 선언과 동시에 반드시 초기화되어야 하고, 한 번 참조한 대상을 다른 대상으로 변경할 수 없습니다.

---

### 참조에 의한 호출의 장점

주소에 의한 호출(포인터)과 비교했을 때, 참조에 의한 호출이 가지는 주요 장점은 다음과 같습니다.

1. **코드의 가독성 및 직관성 향상**
   함수 호출 시 주소 연산자(`&`)를 붙이거나, 함수 내부에서 값에 접근할 때 역참조 연산자(`*`)를 매번 사용할 필요가 없습니다. 문법이 값에 의한 호출과 유사하여 코드가 깔끔해지고 작성 및 읽기가 매우 편리해집니다.

2. **메모리 접근 안정성 확보 (Null 참조 방지)**
   포인터는 아무것도 가리키지 않는 `nullptr` 상태일 수 있어, 함수 내부에서 유효성 검사 없이 역참조할 경우 심각한 런타임 에러(Segmentation Fault)를 유발할 수 있습니다. 반면, 참조자는 문법적으로 널(Null) 할당을 허용하지 않고 반드시 유효한 객체와 바인딩되어야 하므로 상대적으로 매우 안전합니다.

3. **의도치 않은 재할당 방지 (불변성 제어)**
   포인터 변수는 함수 내부에서 연산을 통해 다른 메모리 주소를 가리키도록 변경될 위험이 존재합니다. 하지만 참조자는 한 번 특정 변수의 별칭으로 초기화되면 다른 변수를 참조하도록 재할당할 수 없으므로, 메모리 주소가 잘못 변경되는 논리적 오류를 원천적으로 차단할 수 있습니다.
