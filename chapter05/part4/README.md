# 실습과제 1

### 1. 일반 생성자와 복사 생성자의 차이
* **일반 생성자 (Normal Constructor):** 객체가 메모리에 새롭게 할당되고 생성될 때 호출되며, 전달받은 인수나 설정된 기본값을 통해 객체의 멤버 변수들을 초기 상태로 세팅하는 역할을 합니다.
* **복사 생성자 (Copy Constructor):** 객체가 새롭게 생성될 때, 이미 존재하는 동일한 클래스 타입의 다른 객체를 인수로 참조하여 그 원본 객체의 데이터(상태)를 그대로 복사해 새로운 객체를 초기화합니다. 주로 객체를 값으로 전달(Pass-by-value)하거나, 함수에서 객체를 값으로 반환할 때, 또는 기존 객체를 대입하여 새로운 객체를 선언할 때(예: `ClassName obj2 = obj1;`) 호출됩니다.

### 2. 대입 연산과 얕은 복사 생성자의 차이
두 방식 모두 멤버 변수들을 1대1로(비트 단위로) 복사한다는 점은 같지만, **객체의 생존 주기(Lifecycle)상 호출되는 시점과 목적**에 명확한 차이가 있습니다.
* **얕은 복사 생성자:** **새로운 객체가 생성되는 시점**에 한 번 호출됩니다. 대상 객체는 이제 막 메모리를 할당받은 빈 상태이므로, 단순히 원본 객체의 값을 채워 넣는 초기화 과정만 수행합니다.
* **대입 연산 (Assignment Operation, `operator=`):** **이미 생성되어 데이터(자원)를 가지고 있는 기존 객체**에 다른 객체의 값을 덮어씌울 때 호출됩니다. 대상 객체가 이미 동적 할당된 메모리나 자원을 점유하고 있을 수 있으므로, 메모리 누수를 방지하기 위해 기존 자원을 해제한 후 새로운 값을 대입하는 등의 추가적인 관리가 필요할 수 있습니다. 

### 3. 컴파일러가 자동으로 추가하는 멤버 함수 (4가지)
클래스 설계 시 개발자가 명시적으로 선언하지 않으면, C++ 컴파일러가 암시적으로(Implicitly) 자동 생성해 주는 기본 멤버 함수는 다음 4가지입니다.
1. **기본 생성자 (Default Constructor):** 인수를 받지 않고 객체를 생성하는 생성자입니다.
2. **소멸자 (Destructor):** 객체의 생명주기가 끝나 메모리에서 소멸될 때 호출되는 함수입니다.
3. **복사 생성자 (Copy Constructor):** 동일한 객체를 통해 초기화할 때 얕은 복사를 수행하도록 자동 생성됩니다.
4. **복사 대입 연산자 (Copy Assignment Operator):** 기존 객체에 다른 객체를 대입할 때 얕은 복사를 수행하는 대입 연산자입니다.
