# 실습과제 1

## 1. 참조에 의한 호출(Call by Reference)의 장점

참조에 의한 호출은 변수의 복사본을 생성하지 않고, 실제 변수의 주소(별명)를 전달하는 방식입니다.

*   **메모리 사용량 측면:**
    인수를 전달할 때 새로운 객체를 생성하거나 복사하지 않습니다. 특히 **크기가 큰 구조체나 클래스 객체**를 전달할 때, 복사본을 위한 추가적인 스택 메모리 할당이 필요 없으므로 메모리 절약 효과가 매우 큽니다.
*   **처리 시간 측면:**
    데이터를 복사하는 과정(복사 생성자 호출 등)이 생략됩니다. 대용량 데이터를 다룰 때 복사 오버헤드가 사라지기 때문에 **함수 호출 속도가 현저히 향상**됩니다.

---

## 2. C++ 언어 함수의 반환 과정 (Return Process)

함수가 값을 반환할 때 내부적으로는 다음과 같은 단계를 거칩니다.

1.  **반환 값 생성:** 함수 종료 시 `return` 문에 명시된 값을 가져옵니다.
2.  **임시 객체 생성:** 반환형이 값(Value)인 경우, 컴파일러는 해당 값을 호출한 곳으로 전달하기 위해 **임시 객체(Temporary Object)**를 생성하고 값을 복사합니다.
3.  **스택 프레임 정리:** 함수의 지역 변수와 매개변수가 스택 메모리에서 해제됩니다.
4.  **값 전달 및 대입:** 생성된 임시 객체의 값이 호출부의 변수에 복사된 후, 임시 객체는 소멸합니다.
    *   *참고: 최신 컴파일러는 RVO(Return Value Optimization)를 통해 이 복사 과정을 생략하기도 합니다.*

---

## 3. 반환형이 참조로 선언된 경우 (Reference Return)

함수의 반환형이 `int&`와 같이 참조형인 경우, 반환값은 **"변수 그 자체"**를 의미합니다.

*   **L-value로서의 역할:** 반환된 결과가 임시 값이 아니라 실제 메모리 공간을 가리키므로, 함수 호출 식을 대입 연산자의 왼쪽에 둘 수 있습니다.
*   **주의사항:** 함수 내부의 지역 변수를 참조로 반환해서는 안 됩니다. 함수가 종료되면 지역 변수는 소멸하므로, 존재하지 않는 공간을 가리키는 **Dangling Reference** 문제가 발생합니다. 따라서 주로 외부에서 전달받은 인스턴스나 전역 변수, 정적 변수를 반환할 때 사용합니다.

---

## 4. 참조 리턴 응용 예제: 연산자 오버로딩 (C++)

참조 리턴이 가장 흔히 사용되는 예는 **출력 연산자(`<<`) 오버로딩**이나 **배열 요소 접근**입니다. 아래는 배열의 특정 요소를 참조로 반환하여 값을 수정하는 예제입니다.

```cpp
#include <iostream>
using namespace std;

int& getElement(int arr[], int index) {
    // 배열의 특정 요소를 참조로 반환
    return arr[index];
}

int main() {
    int myTable[5] = {1, 2, 3, 4, 5};

    // 함수 호출 식이 대입 연산자의 왼쪽에 위치 (L-value)
    getElement(myTable, 2) = 100; 

    for(int i = 0; i < 5; i++) {
        cout << myTable[i] << " ";
    }
    // 출력 결과: 1 2 100 4 5

    return 0;
}
```
