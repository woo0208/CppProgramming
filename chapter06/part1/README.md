# C언어와 C++의 함수 호출 결정 방식 차이

C언어와 C++의 가장 큰 차이는 **함수 오버로딩(Overloading)의 지원 여부**에 있으며, 이를 처리하기 위해 컴파일러는 서로 다른 방식으로 함수의 이름을 관리합니다.

---

## 1. C언어: 함수 이름을 통한 단순 결정

C언어는 "한 스코프 내에서 함수의 이름은 유일해야 한다"는 원칙을 따릅니다.

*   **네임 맹글링 없음:** C 컴파일러는 작성된 함수 이름을 그대로 사용하거나, 아주 단순한 규칙(예: 앞에 언더바 `_` 추가)만 적용하여 심볼을 만듭니다.
*   **결정 방식:** 오직 **함수의 이름**만으로 호출할 함수를 결정합니다.
*   **특징:**
    *   매개변수가 달라도 이름이 같으면 중복 정의 에러가 발생합니다.
    *   예: `square_int(int x)`, `square_double(double x)`처럼 용도별로 이름을 다르게 지어야 합니다.

---

## 2. C++: 네임 맹글링(Name Mangling)을 통한 결정

C++은 **함수 오버로딩**을 지원하므로, 이름이 같더라도 매개변수가 다르면 서로 다른 함수로 인식해야 합니다.

*   **네임 맹글링(Name Mangling):** 컴파일러가 함수의 이름, 매개변수의 개수, 타입, 리턴 타입 등의 정보를 조합하여 고유한 내부 식별자를 생성하는 과정입니다.
*   **결정 방식:** **함수 이름 + 매개변수 리스트(타입, 순서, 개수)**를 모두 조합하여 호출할 함수를 결정합니다.
*   **특징:**
    *   동일한 이름의 함수가 여러 개 존재할 수 있습니다.
    *   컴파일 타임에 인자 값을 보고 가장 적합한 맹글링된 이름을 찾아 연결합니다.

---

## 3. 비교 요약

| 구분 | C언어 | C++언어 |
| :--- | :--- | :--- |
| **핵심 개념** | 식별자 유일성 (Unique Name) | 함수 오버로딩 (Overloading) |
| **심볼 생성** | 함수 이름 그대로 사용 | 이름 + 매개변수 정보를 조합 (Mangling) |
| **중복 정의** | 이름이 같으면 무조건 에러 | 이름이 같아도 매개변수가 다르면 허용 |
| **컴파일러 행동** | `void func(int)` → `_func` | `void func(int)` → `__func_i` (예시) |
