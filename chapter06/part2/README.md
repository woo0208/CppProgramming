# 실습과제 1

## C++ 디폴트 매개변수를 선언에 정의해야 하는 이유

C++에서 디폴트 매개변수(Default Parameter)는 일반적으로 함수의 정의(Definition)가 아닌 선언(Declaration)에 기술해야 합니다. 그 이유와 정의부에 작성했을 때의 현상은 다음과 같습니다.

---

### 1. 선언부(Header/Prototype)에 정의해야 하는 이유

가장 핵심적인 이유는 **컴파일러의 컴파일 방식** 때문입니다.

*   **컴파일 시점의 결정:** 컴파일러는 소스 코드를 위에서 아래로 읽으며 기계어를 생성합니다. 함수를 호출하는 코드(`func();`)를 만났을 때, 컴파일러는 해당 함수의 **선언부**를 참조하여 문법을 검사합니다.
*   **코드 보정:** 컴파일러는 선언부에 명시된 디폴트 값을 보고, 사용자가 생략한 인자를 자동으로 채워 넣어 기계어를 완성합니다.
    *   예: 선언이 `void func(int a = 10);`일 때, `func();` 호출을 보면 컴파일러가 이를 `func(10);`으로 해석하여 컴파일합니다.
*   **독립적 컴파일:** C++은 파일 단위로 컴파일됩니다. 함수 호출부가 있는 파일에서 함수의 실제 구현부(정의)가 있는 다른 파일을 일일이 뒤져서 기본값을 찾아내기란 구조적으로 어렵습니다.

---

### 2. 함수의 정의(Definition)에만 기술했을 경우

만약 선언부에는 기본값을 적지 않고, 함수의 실제 몸체가 있는 정의부에만 기본값을 기술하면 다음과 같은 문제가 발생합니다.

#### ❌ 컴파일 에러 발생
```cpp
// 1. 선언부: 기본값이 없음
void PrintData(int a); 

int main() {
    // 2. 호출부: 인자를 생략함
    PrintData(); // Error: 함수에 인자가 너무 적습니다!
    return 0;
}
// 3. 정의부: 여기에만 기본값을 설정함
void PrintData(int a = 100) { 
    std::cout << a << std::endl;
}
```
